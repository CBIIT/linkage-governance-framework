# Accelerate Data Governance for Linkage Today  

While the comprehensive Linkage Governance Framework is still a concept, you don’t have to wait to start seeing its benefits. Investigators, requesting institutions, and data stewards can unlock significant value right now by integrating selected framework elements into your current workflows. 

If you are pursuing a study that involves linking data from multiple sources, use these resources to help you organize discussions, streamline preparation, and tackle complex data governance questions with consistency and confidence. 

Our objective is to put useful, actionable tools in your hands today while the broader framework continues to evolve. 

## Support the Work You Already Do 

Many elements of this framework are explicitly built to support the essential responsibilities that investigators, requesting institutions, and dataset holders already tackle every day. You can leverage these materials to:

- **Clarify Operations:** Better understand the rough order and sequence of operations required to propose and initiate a research linkage effort. 
- **Anticipate Needs:** Identify the critical information and planning steps necessary before engaging  with a dataset holder. 

## Key Resources Available Now

You can start using these implementation materials today. They are not intended as a rigid, one-size-fits-all sequence—every linkage effort involves different data, rules, stakeholders, and institutional constraints. Instead, view them as adaptable starting points. 

- [Playbook](/resources#playbook) — can frame discussions between investigators and dataset holders about governance needs, roles, decision points, and implementation considerations. 
- [Request Package Overview](/resources#request-package) — can help investigators think through what information may be needed to prepare for a linkage request. 
- [Linkage Planning Workbook](/resource#linkage-request-planning-workbook) - can guide the investigator when planning multiple requests to access data for linking individual-level health data in research. 
- [Rule Harmonization Protocol](/resources#rule-harmonization) — can be piloted by investigators and legal experts at requesting institutions to retrieve, process, and harmonize rules across datasets being considered for linkage. 
- [NICHD Record Linkage Implementation Checklist](https://github.com/NIH-NICHD-Ecosystem/E2_Record-Linkage-Implementation-Checklist/) – stakeholder teams can use this to guide governance and technical decisions that must be made prior to designing and implementing a strategy for linking data from multiple sources and sharing and using the linked datasets for research.  
- [NICHD Data Governance Metadata Schema](https://github.com/NIH-NICHD/Data-Linkage-Governance/tree/main/MetadataSchema) – investigators, requesting institutions, or dataset holders can use this to annotate and/or structure data governance information relevant to accessing, sharing, linking, and using individual-level participant data. Data governance metadata can then be used for an analysis of linkage feasibility.
- [NICHD Generative AI Rules Analysis](https://github.com/NIH-NICHD-Ecosystem/E6-Protecting-scientific-data-when-using-generative-AI) – can be referenced for any data integration rules analysis,  and demonstrates how an investigators’ data protection obligations may conflict with their use of public GenAI tools, using the NICHD data governance metadata schema. 
 

You can choose to use a single resource to guide internal planning, leverage another to prep a specific linkage effort, or test whether a more structured governance approach fits your unique setting. Because linkage efforts vary, the “right” tool depends on your specific datasets, partners, and governance hurdles.  

The goal is not to require full adoption of the framework at once, but to make useful parts available now while the broader approach continues to evolve.
